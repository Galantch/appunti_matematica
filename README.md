# 📐 appunti_matematica

Repository con gli appunti di **matematica dalla terza alla quinta superiore**, a disposizione di tutti.

> 🚧 **Stato:** in corso – gli appunti vengono aggiornati progressivamente.

Gli appunti sono scritti in **LaTeX** e sono disponibili anche in formato **PDF**.

---

## 📁 Contenuto

| File | Descrizione |
|---|---|
| `appunti_matematica.tex` | Sorgente LaTeX degli appunti |
| `appunti_matematica.pdf` | Appunti già compilati, pronti da leggere |

---

## 📖 Come consultare gli appunti

Per leggerli basta aprire il file **`appunti_matematica.pdf`** direttamente da GitHub o scaricarlo.

## 🛠️ Come compilare il sorgente

Per ottenere il PDF a partire dal sorgente serve una distribuzione LaTeX (ad esempio TeX Live o MiKTeX): compila il file `appunti_matematica.tex` con il compilatore LaTeX che preferisci.
